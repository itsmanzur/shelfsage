ShelfSage Documentation

Complete WooCommerce bookstore toolkit — book taxonomies, shortcode builder, Vault, Look Inside, affiliate links, Amazon & Google APIs, purchase-gated e-book downloads, and SEO schema in one package.

Version 1.5.1 WordPress 5.8+ WooCommerce 7.0+ PHP 7.4+ HPOS Ready Cart/Checkout Blocks

Welcome to ShelfSage

Thank you for purchasing ShelfSage. This is the complete documentation that ships with the plugin (you are reading shelfsage/documentation/index.html). Bookmark it locally — every section below is self-contained and works offline.

What it does

Turns any WooCommerce store into a specialised bookstore with author / publisher / series taxonomies, custom single-product templates, shortcode builder, and SEO schema.

Who it's for

Online bookstores, publishers, libraries, author websites, educational sites, multilingual book shops, and book review blogs.

What's inside

15+ admin features, 6 single-product designs, 5 vault layouts, 9 frontend components, REST API, Gutenberg blocks, Elementor widget, and a React + Vite build environment.

Installation

Method 1 — Upload via WordPress admin

  1. Log in to WordPress Admin → Plugins → Add New → Upload Plugin.
  2. Choose shelfsage.zip and click Install Now.
  3. Click Activate Plugin.
  4. You are automatically redirected to the ShelfSage Welcome wizard.

Method 2 — FTP / SFTP

  1. Unzip shelfsage.zip on your computer.
  2. Upload the shelfsage folder to /wp-content/plugins/.
  3. Go to Plugins → Installed Plugins and click Activate.
WooCommerce required ShelfSage extends WooCommerce. If WooCommerce is not active, install and run the WC setup wizard first.

First-Run Wizard

On first activation ShelfSage opens a 4-step wizard:

  1. Welcome & preferences — choose enabled taxonomies (Authors, Publishers, Translators, Series, Genres) and your bookstore type.
  2. Demo content — optionally import a sample catalogue with covers, authors, and series so you can preview every layout immediately.
  3. Look & feel — pick a default single-product layout and accent color.
  4. Connect — add Google Books / Amazon credentials (optional, can be skipped and added later in Settings → Connect & Data).
Tip You can re-open the wizard any time from ShelfSage → SS Dashboard → Welcome.

  • Primary / accent color — drives buttons, badges, and the countdown widget.
  • Border radius — global corner radius for cards and buttons.

Settings → Features

  • Look Inside — show a preview button on books with _rmss_look_inside_url.
  • PDF Reader Engine — basic browser viewer, mobile PDF.js, or 3D Flipbook.
  • Affiliate buttons — show external buy buttons (Amazon, Rokomari, etc.).
  • Schema markup — emit JSON-LD for Book / Author / Publisher.
  • Advanced Schema — add co-author, awards, bookFormat, bookEdition, etc.
  • Custom button — second CTA next to Add to Cart.
  • Hide Add to Cart — for catalogue-only stores.

Settings → Labels

Override the default English strings shown on product pages: Add to Cart, Look Inside, View Cart, Related Books, Pre-order, Download e-book, etc.

Each label is also exposed via the rmss_get_label() helper and a rmss_label_{key} filter so a child theme can override it programmatically.

Settings → Connect & Data

  • Google Books API key — used by Smart Book Ingester and Smart Fallback. Stored in wp_options.shelfsage_settings, never exposed to the frontend.
  • Amazon PA-API v5 credentials — Access Key, Secret Key, Associate Tag. AES-256 Secret Keys are encrypted at rest with openssl_encrypt('aes-256-cbc', …).
  • Smart Fallback — when Amazon data is incomplete, auto-fetch missing cover / description from Google Books.
  • Test Connection — single-click Google Books validation with latency reading.

Single Product Templates

Six designs ship out of the box. Choose under Settings → General → Single Product Layout:

  • classic — original ShelfSage design with Digital section, share, and metadata table.
  • style-1 — Modern Clean (default).
  • style-2 — Minimalist.
  • style-3 — 3D Shelf.
  • style-4 — Negative Space (sans-serif typography).
  • style-5 — Brutalist.

All templates are mobile-responsive (titles scale via text-[1.75rem] md:text-[2rem] classes) and respect the configured Pre-order Countdown.

Theme overrides

Copy any template into your-theme/shelfsage/ to override it. ShelfSage looks for theme overrides via locate_template() before falling back to its own copy.

Shortcode Architect

A no-code visual builder at ShelfSage → Shortcode Architect. Three tabs:

  1. Fetch Data — choose data source (WooCommerce, Vault, Google Books, Amazon), filters, sort & order.
  2. Layout — pick mode (grid / list / masonry / slider), columns, gap, image height.
  3. Designer — pick a card design (Classic Card, Modern Clean, Minimalist, 3D Shelf, Slide-Out, Negative Space, Brutalist, 3D Flip), toggle visible elements, set radius and alignment.

The generated shortcode is pinned at the top of the panel. Copy and paste into any page, post, widget, or block.

Saved shortcodes

Click Save to persist a configuration. Reuse via [shelfsage id="3"]. Saved shortcodes are listed in ShelfSage → Saved Shortcodes.

Vault — Catalogue Without WooCommerce

Use the Vault when you want to display books that are not for sale (a library catalogue, an upcoming-titles board, an author bibliography). Vault entries don't create WooCommerce products and don't add to cart.

  • Add to Vault: ShelfSage → Library → Add to Vault.
  • Display: [shelfsage_vault] shortcode, or pick "Vault" as the data source in the Shortcode Architect.
  • Layouts: 5 vault designs in templates/vault-layouts/.

Look Inside (PDF / Image Preview)

Add a Look Inside URL to a product (PDF or image). When a visitor clicks the Look Inside button, ShelfSage opens the file in a modal.

PDF Reader Engine

Settings → Features → PDF Reader Engine controls how PDFs are rendered:

  • Basic — browser-native PDF viewer (lightest).
  • Mobile PDF.js — page-by-page viewer with pinch-zoom; also used as automatic fallback on phones.
  • 3D Flipbook New — page-flip animation powered by StPageFlip. Bundle is shipped at assets/pageflip/page-flip.browser.js; if missing it auto-falls back to the cdnjs CDN.

Security

The viewer endpoint (includes/pdf-viewer.php) is nonce-protected and refuses any URL that is not registered as a Look Inside URL on a published product, preventing SSRF abuse.

Pre-order Countdown New in 1.5.1

Show a 4-unit (Days / Hours / Minutes / Seconds) countdown on books with a future Release Date.

Setup

  1. Open the product editor → Book Details.
  2. Set Pre Order Availability to Yes.
  3. Pick a future Release Date in the date picker.
  4. Save the product. The countdown appears automatically:
  • On every ShelfSage single-product template (all 6 styles).
  • On stock WooCommerce templates via woocommerce_single_product_summary at priority 25 (between excerpt and Add to Cart).
  • Anywhere you drop the shortcode: [shelfsage_preorder_countdown id="123"].

A static $rendered_for[] guard prevents the countdown from appearing twice on the same page.

Disable the auto-injection

add_filter( 'trsss_auto_inject_preorder_countdown', '__return_false' );

Book Condition Badge New in 1.5.1

For second-hand bookstores (a huge market in South Asia and on Marketplace / OLX-style channels). A colour-coded badge near the title surfaces book condition transparently to buyers.

Setup

  1. Open the product editor → Book Details.
  2. Pick a value from Book Condition:
    • Not specified — badge hidden (default for new-only retail stores).
    • New — green badge "New".
    • Used – Like New — teal badge.
    • Used – Good — blue badge "Used – Good Condition".
    • Used – Acceptable — amber badge.
    • Used – Poor — red badge.
  3. Save the product. The badge appears automatically:
  • Inside all six ShelfSage single-product templates (next to the Pre-order Countdown).
  • On stock WooCommerce templates via woocommerce_single_product_summary at priority 8 (between title and price).
  • Anywhere via shortcode: [shelfsage_book_condition id="123"].

SEO benefit

Book Condition is automatically pushed into the JSON-LD Book schema as itemCondition (schema.org/UsedCondition, NewCondition, or DamagedCondition) — Google Shopping uses this field for product cards.

Age Rating / Content Advisory Badge New in 1.5.1

A small colour-coded pill that surfaces who the book is appropriate for. Useful for general-interest stores, school libraries, and parents shopping for children's books. Also pushed into the JSON-LD Book schema as contentRating + typicalAgeRange so Google can render the rating directly on rich results.

Setup

  1. Open the product editor → Book Details.
  2. Pick a value from Age Rating / Content Advisory:
    • Not specified — badge hidden (default).
    • 🟢 All Ages — green pill.
    • 🔵 Children (under 12) — blue pill, schema age range 5–11.
    • 🟡 Teen 13+ — amber pill, schema age range 13–17.
    • 🟠 Young Adult 16+ — orange pill, schema age range 16–18.
    • 🔴 Adult 18+ — red pill, schema age range 18–.
  3. Save the product. The badge appears automatically:
  • Inside all six ShelfSage single-product templates next to the Book Condition badge.
  • On stock WooCommerce templates via woocommerce_single_product_summary at priority 9 (between Book Condition at 8 and rating / price at 10).
  • Anywhere via shortcode: [shelfsage_age_rating id="123" icon="yes"].

Legacy value migration

If you imported books from another system that stored age ratings as free-text, the renderer auto-maps common variants to the canonical slugs so you don't need to bulk-edit:

Stock Alerts (Email) New in 1.5.1

The Inventory dashboard shows low-stock counts at a glance, but most shop owners do not log in every day. This module sends a customised HTML email the moment a book drops at or below the threshold (low stock) or runs out completely (no stock).

Setup

  1. Make sure WooCommerce → Products → Inventory → Manage stock is enabled on each product (or globally in WooCommerce → Settings → Products → Inventory).
  2. Open ShelfSage → Settings → Features → Inventory Alerts.
  3. Toggle Enable Low / Out-of-Stock Email Alerts.
  4. Set Low Stock Threshold (default 5).
  5. Add one or more Alert Email Recipient(s) — comma- or semicolon-separated. Leave blank to use the WordPress admin email.
  6. Save Settings.

What the email contains

  • Book cover thumbnail.
  • Book title and ISBN (from _rmss_isbn).
  • Current stock quantity vs configured threshold.
  • "Edit Product" and "View Product" buttons.
  • "Out of Stock" badge for the no-stock variant.

Throttle behaviour

WooCommerce fires woocommerce_low_stock on every stock change, which would normally flood the inbox during bulk edits. ShelfSage stores a 12-hour transient per product per alert type (trsss_stock_alert_low_{id} / trsss_stock_alert_no_{id}), so each book can only generate one alert per cycle. The throttle is automatically cleared the moment stock is replenished above the threshold, so the next dip below threshold sends a fresh alert immediately.

Multiple recipients Add comma-separated addresses, e.g. owner@store.com, manager@store.com, warehouse@store.com. Invalid addresses are silently dropped.

Filters & actions

HookTypePurpose
trsss_stock_alerts_enabledfilter (bool)Force-disable alerts (e.g. on a staging site).
trsss_stock_alert_thresholdfilter (int)Override the threshold programmatically (e.g. per category).
trsss_stock_alert_recipientsfilter (array)Add or remove recipients per product / alert type.
trsss_stock_alert_subjectfilter (string)Customise the email subject.
trsss_stock_alert_htmlfilter (string)Replace the entire HTML body.
trsss_stock_alert_throttlefilter (int seconds)Change the per-product cooldown. Default 12 × HOUR_IN_SECONDS.
trsss_stock_alert_should_sendfilter (bool)Skip alerts for specific products (e.g. digital books).
trsss_stock_alert_sentactionFires after dispatch (or skip). Useful for logging.

Example: skip alerts for digital products

add_filter( 'trsss_stock_alert_should_send', function ( $allow, $product, $type ) {
    if ( $product->is_virtual() || $product->is_downloadable() ) {
        return false;
    }
    return $allow;
}, 10, 3 );

Example: lower throttle to 2 hours during sale events

add_filter( 'trsss_stock_alert_throttle', function () {
    return 2 * HOUR_IN_SECONDS;
} );

E-book Download Gate SecurityNew in 1.5.1

Replaces the public _rmss_ebook_url link with a purchase-verified flow. The raw URL is never reflected in HTML any more.

How it works

  1. Customer buys the book and the order reaches status completed or processing.
  2. WooCommerce sends the customer email; ShelfSage hooks woocommerce_email_after_order_table and appends a "Your e-book downloads" section with HMAC-SHA256 signed URLs (default 30-day expiry).
  3. The customer (logged in or guest) clicks the link. template_redirect validates the HMAC, re-checks the order status and product membership, increments a download counter on the order, then either streams the local upload file (with a realpath() traversal guard) or 302-redirects to external storage (Dropbox, S3, Bunny.net).
  4. On the product page, logged-in buyers also see a live "Download e-book" button next to Add to Cart.

URL shape

https://example.com/?shelfsage_ebook_download=1&order=123&product=456&exp=1779999999&token=abcd1234…

Filters

FilterDefaultPurpose
trsss_ebook_token_ttl30 * DAY_IN_SECONDSLifetime of a generated download URL.
trsss_ebook_paid_statuses['completed','processing']Which order statuses unlock downloads.
trsss_ebook_email_ids['customer_completed_order','customer_processing_order']Which email IDs receive the download section.
trsss_ebook_locked_labelBuy to download e-bookLabel shown to guests / non-buyers.
Security model Tokens are HMAC-SHA256 signed with wp_salt('auth'), expire automatically, and are bound to a specific (order × product) pair. Local files are streamed only after realpath() confirms they live inside wp_get_upload_dir()['basedir'].

Reading List / Wishlist

Logged-in customers can save books to a personal "My Library" from any product page.

  • Add button: appears on single-product templates.
  • Customer page: /my-library/ endpoint.
  • Embed elsewhere: [shelfsage_reading_list] shortcode.
  • Performance: the REST response uses _prime_post_caches() to resolve the N+1 query problem (50 books → 1–2 queries instead of 150+).

Analytics Dashboard

See most-viewed books and search-term trends at ShelfSage → SS Dashboard → Insights.

  • Most Viewed — populated by template_redirect increment of _rmss_view_count.
  • Search Trends — populated by ShelfSage REST /search calls.
  • Performance: bot detection (Googlebot, Bingbot, DuckDuckBot, Baidu, curl, wget) plus a 24-hour setcookie dedup eliminates redundant update_post_meta writes on every visit.

Goodreads Library Export — direct import New in 1.5.1

Goodreads is the world's largest reading-list service. ShelfSage detects the Goodreads "Export Library" CSV automatically — no manual column mapping required.

How to get the file from Goodreads

  1. Sign in at goodreads.com.
  2. Open My Books → Tools → Import and export.
  3. Click Export Library. Goodreads emails you (or links you to) goodreads_library_export.csv.

Then in ShelfSage

  1. Open ShelfSage → SS Dashboard → Library → Bulk Import.
  2. Drop goodreads_library_export.csv into the dropzone.
  3. An emerald "📚 Goodreads Library Export detected" banner appears on step 2 — confirm and click Import.

Force the format from REST / WP-CLI

If you're calling POST /wp-json/shelfsage/v1/import-books from a script, pass format=goodreads in the JSON body to bypass auto-detection:

POST /wp-json/shelfsage/v1/import-books
{
  "target": "woocommerce",
  "format": "goodreads",
  "rows": [ { "Title": "…", "Author": "…", "ISBN": "=\"0743273567\"", … } ]
}

Filter

Add or override mapped fields with trsss_normalize_goodreads_row:

add_filter( 'trsss_normalize_goodreads_row', function ( $normalized, $row ) {
    // Push Goodreads "Date Read" into a custom postmeta key.
    if ( ! empty( $row['Date Read'] ) ) {
        $normalized['date_read'] = sanitize_text_field( $row['Date Read'] );
    }
    return $normalized;
}, 10, 2 );

Troubleshooting

The custom single-product template is not loading

  • Check Settings → General → Use ShelfSage Custom Template is enabled.
  • If Apply to all products is off, the product must have at least one ShelfSage taxonomy term assigned.
  • Some themes hijack template_include at higher priority. ShelfSage runs at priority 9999, but heavy page builders (e.g. Divi shop modules) may still win — disable the builder for product pages or use the override file in your theme: your-theme/shelfsage/single-product-shelfsage.php.

Look Inside flipbook shows a blank page

  • Check assets/pageflip/page-flip.browser.js exists in the installed plugin folder. If missing the inline PHP fallback uses cdnjs — confirm the site can reach https://cdnjs.cloudflare.com.
  • Open browser DevTools → Console. A 404 on page-flip.browser.js indicates the asset was excluded from your zip.

E-book download link returns 403

  • The token has expired (default 30 days). Resend the order email or have the customer re-trigger from My Account.
  • The order status is not in the unlocked list. Filter trsss_ebook_paid_statuses if your shop uses custom statuses.

Bengali product title shows as mojibake (à¦š…)

ShelfSage already filters the_title and the_content at priority 1 to fix display-time mojibake. To repair the database itself, visit /wp-admin/?action=trsss_repair_product_slugs&_wpnonce=….

Analytics counter not updating

ShelfSage skips counting bots and uses a 24-hour cookie to avoid re-counting the same visitor. Open the page in an incognito window with a different IP/UA to verify.

"Plugin is not compatible with HPOS" or "Cart/Checkout Blocks" warning in WooCommerce

Make sure you are on ShelfSage 1.5.1 or later — both compatibility flags are declared in shelfsage.php via FeaturesUtil::declare_compatibility('custom_order_tables', __FILE__, true) (HPOS) and FeaturesUtil::declare_compatibility('cart_checkout_blocks', __FILE__, true) (Cart / Checkout Blocks). Open WooCommerce → Settings → Advanced → Features and confirm both rows show a green tick.

FAQ

Does this work with any WooCommerce theme?

Yes. ShelfSage uses its own styling for book grids and details. Single-product templates can be overridden per theme by copying the file into your-theme/shelfsage/.

Can I disable certain taxonomies?

Yes. Choose the enabled taxonomies in the first-run wizard, or via ShelfSage → Settings → General → Active Taxonomies.

Is WooCommerce required?

Yes for purchase / cart / checkout flows. The Vault module works without WooCommerce for catalogue-only use.

Where is my Google Books API key stored?

In the shelfsage_settings WordPress option. It is only used server-side by wp_remote_get and is never exposed to the frontend.

Where is my Amazon Secret Key stored?

Encrypted at rest with AES-256-CBC (openssl_encrypt) in includes/class-shelfsage-credential-store.php. The encryption key is derived from wp_salt('auth'), so secrets are bound to your specific WordPress installation.

What data does ShelfSage send to Google or Amazon?

Only the data necessary for the requested operation: search queries (ISBN, title, or keyword) and your configured API credentials. No personal user data is sent. See External Services.

Does ShelfSage support multisite?

Yes — activate per-site (network activation works but per-site settings are still required because each site has its own product catalogue).
